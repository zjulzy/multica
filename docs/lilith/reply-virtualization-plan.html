长回复串逐条虚拟化

目标：只挂载可视区及缓冲区的回复，减少长串展开、收起时的渲染与布局成本，并保留用户熟悉的评论交互。

实施顺序

  1. 梳理回复顺序、已解决状态及智能体运行插槽；为可见范围和定位边界补测试。
  2. 虚拟化长回复串中的单条回复，使用现有滚动容器；短串和页内搜索保留完整渲染。
  3. 接通定位：先将目标回复移入渲染范围，再精确对齐；编辑中的回复保持挂载，草稿和折叠状态不因滚动丢失。
  4. 验证回复动效、滚动锚点、图片尺寸变化、回复发送和长串搜索；比较长 Issue 的 DOM 数量及交互耗时。

验收

逐条折叠和动效开关行为保持一致；长串只渲染必要行；深链、未读、智能体运行状态、评论编辑与搜索可用。性能数据和开发版手感均需实测。
