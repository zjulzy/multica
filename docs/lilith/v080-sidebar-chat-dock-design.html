已确定的行为

  • 侧栏视觉：左侧竖排导航与可伸缩侧栏使用同一背景与连续边界；主页面仍保留独立的内容面板。支持现有主题、收起和拖动宽度。
  • 智能体运行栏：统一固定在左侧竖栏，设置和账户入口的上方；不再随页面切换位置。运行栏根据窗口高度限高，超出时只在运行栏内部滚动，保证设置和账户入口仍可访问；沿用现有开关、状态动效和点击行为。
  • 底栏开关：开启底栏模式时，隐藏左侧竖排的收件箱和聊天入口；关闭底栏模式时恢复。因为点击运行栏临时打开的底栏不改变该开关。
  • 聊天：底栏增加与收件箱、智能体并列的聊天按钮，使用已有聊天能力，包括会话列表、选择会话、新建聊天和消息输入。切换页签只替换底栏内容，不切换或遮挡当前主页面；继续沿用现有拖动、折叠和动效设置。
  • 聊天跳转：底栏模式开启时，点击聊天通知、智能体的“发消息”等入口会展开底栏，选中聊天并定位相应会话或智能体。底栏关闭时先展开。工作区不同时先切换到目标工作区，再定位聊天。
  • 收件箱：现有 Dock 操作、未读跳转和主页面收件箱保持可用；已隐藏入口不会让深链接失效。

实现时要守住的细节

场景预期
切换底栏标签收件箱、智能体、聊天互相切换；再次点击当前标签遵循现有折叠规则。
聊天数据与草稿沿用官方聊天控制器和现有会话数据，不新建服务端存储；草稿和发送状态不因 Dock 切换而误丢失。底栏聊天激活时避免旧聊天页同时改写会话和地址。
工作区与深链接统一处理普通聊天链接、智能体“发消息”和搜索；跨工作区请求等目标工作区加载后再定位，多次快速跳转以后一次为准。会话失效或无权限时提示，不跳进错误会话；保留修饰键打开新标签的行为。
未读提示隐藏左侧入口后，底栏聊天按钮保留未读提示。只有窗口在前台、底栏展开且聊天标签被选中时，才将当前会话视为正在阅读；切换标签、折叠或切到后台不自动清除未读。
主页面与悬浮聊天启用底栏时如果当前已在主页面聊天，先保留当前页面；打开底栏聊天后不让两个界面争抢选择。关闭底栏后主页面可继续使用。保留已有悬浮聊天设置，底栏聊天激活时避免同时展示同一对话。
通知能力当前桌面系统通知链路只提供收件箱定位，没有聊天会话标识；本次保留现有通知行为。若已有聊天入口提供会话或智能体标识，则跳到对应底栏内容；不虚构通知字段。
运行栏尺寸竖栏中给头像独立限高滚动区域，底部帮助、设置和账户入口不随头像滚走；覆盖矮窗口和大量头像。
验收与发布先在开发版验收交互和动画；用户确认后再打包或通过 GitHub 发布。

工程实现选择：优先复用聊天控制器及组件；为底栏隔离页面路由同步，避免聊天选择改写当前主页面地址。独立审查并覆盖开关、跨工作区、折叠和跳转回归。

补充调整

  • 竖排按钮和可伸缩侧栏虽然共用背景，但两者之间保留明确分界线。
  • 运行栏依然可以滚动，滚动条平时隐藏，鼠标悬浮时显示。
