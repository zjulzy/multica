Meego 同步客户端接入

将服务器现有 Meego 同步控制台接入桌面客户端。工作区匹配时在工作侧栏显示入口；界面设置提供开关。

交互

  1. 展示服务运行状态、当前计划、下一次执行时间和同步范围。
  2. 支持指定单号、全量同步（执行前确认），显示返回结果；不得自动触发同步。
  3. 支持每日多个时间、固定间隔或关闭定时，草稿在自动刷新时保留，可保存或放弃。
  4. 展示历史运行记录，按需展开日志，运行中以网页现有频率刷新。

安全与兼容

所有请求只发往当前客户端配置的服务器固定路径，使用当前登录凭据；不输出或保存令牌。服务不存在、登录失效或工作区不匹配时明确提示，不将操作发送到其他服务器或工作区。禁止自动调用同步和计划修改接口。

验证

覆盖 URL 与请求头、失败及作用域、计划草稿、操作触发和日志；运行桌面类型检查，启动开发版验收。测试使用模拟接口，不触发真实同步。
