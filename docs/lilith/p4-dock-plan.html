P4 Dock 实施计划

当前 Issue 的外部单号或 Multica 编号精确匹配本机各工作区的待提交 CL；在 Dock 中查看文件、Diff、填入 Issue 评论草稿及确认后撤销单文件。

数据与安全

Electron 主进程以参数数组调用 P4；限制到当前用户和本机工作区，枚举待提交 CL，再以完整单号筛选。查询具备超时和明确错误状态。Diff 和撤销前重新确认用户、工作区、CL 和文件归属，撤销仅对用户确认的单个文件执行；不执行提交。

交互

Dock 切换 Issue 更新匹配结果，按工作区展示 CL 和文件；Diff 支持选中片段填入当前 Issue 的评论草稿，保留已有内容，不自动发送。缓存 Issue 通过受限消息桥通知正确页面，避免跨 Issue 串写。

验证

覆盖单号边界、工作区隔离、无匹配、Diff 与撤销参数校验、评论草稿保留及缓存页面消息路由；执行相关回归测试和类型检查，开发版在不影响正式客户端的模式下验证。
