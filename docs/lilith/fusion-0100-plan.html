Multica 0.10 融合计划

基线：v0.8.0-lilith.14；上游：v0.10.0。在独立工作区执行，保留现有正式版。

实施顺序

  1. 合并上游，逐项处理冲突，保留双方必要行为和用户已验收的定制。
  2. 检查桌面进程、窗口导航、底栏、固定 Issue 页面缓存与工作区切换。
  3. 融合侧边栏与固定视图、收件箱、聊天、长评论性能和消息定位。
  4. 核对主题、界面设置、统计、性能和 LiWork 页面，以及多语言文案。
  5. 重装依赖，运行类型检查及受影响模块的回归测试；检查真实服务器兼容性。
  6. 启动开发版供验收，待用户确认后再考虑打包发布。

重点：保留嵌套 Issue 元数据兼容、当前用户固定内容和外部链接打开行为。禁止修改服务器数据或覆盖正在运行的正式客户端。
