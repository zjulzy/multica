单层时间线：长回复串性能改造

将长回复串拆成根评论、独立回复、折叠条和输入框等项目，全部交给外层 Virtuoso；移除回复串内部的虚拟列表。保持评论顺序、统一标题、折叠动效及现有跳转行为。

实施步骤

  1. 建立纯数据投影：覆盖回复、运行中的智能体、删除项、已解决状态和整串折叠。
  2. 拆分评论根部、回复行和输入区，保证单条回复在根部不在屏幕中时仍可独立工作；保留草稿、附件和评论定位。
  3. 将投影结果接入外层列表，重做回复、运行记录及新发评论的索引跳转；搜索时仍能找到完整正文。
  4. 处理虚拟行卸载时的编辑和动画，确保未保存内容不丢失，滚动锚点及手动打断跳转有效。
  5. 运行组件、跳转、草稿和智能体状态测试；在真实长 Issue 中比较 DOM 数量、长帧及滚动手感。

验收边界：仅在滚动、编辑、搜索和评论定位都验证通过后替换现有嵌套实现；不因单纯性能收益牺牲草稿安全或原有交互。
