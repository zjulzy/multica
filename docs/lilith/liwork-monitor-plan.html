LiWork 连接与资源面板

左侧新增可关闭的 LiWork 入口，打开带连接列表和详情的主页面，复用 LiWork 自带图标。无需服务端修改。

数据与准确性

  • 只读桥接登记表，列出活跃、启动中和待确认连接；不把历史结束记录算作正在运行。
  • 只读 LiWork 终端列表和资源快照；通过句柄、窗格及进程会话三重校验，匹配失败显示待确认或资源不可用，绝不填零冒充采样值。
  • 统计值仅覆盖已确认的桥接会话，不把 LiWork 共享进程计入单个会话；失败和采样时间在页面说明。
  • 仅面板可见时低频刷新；失败保留可用数据并明确标识，CLI 调用设超时、限流和单次并发。

实施与验证

  1. 实现独立纯数据合并函数和测试，再在主进程添加受限只读 IPC，固定可执行文件与参数。
  2. 建立左侧入口、工作区路由、带列表与详情的页面及界面设置开关；防止跨工作区误跳。
  3. 测试匹配、失联、数据错误、资源数值、权限及 UI 状态；运行类型检查与独立审查。
  4. 开发版主进程变更需要重启后体验；不改正在使用的正式客户端。
