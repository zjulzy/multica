性能总览实施计划

在左侧竖栏增加独立入口。只显示当前值，不存储历史；页面不可见时停止主动采样。

数据与边界

  1. 主进程提供 Electron 进程 CPU 和工作集采样，按 PID 去重；能确定的进程标注主窗口或缓存页面，其余标为其他进程。
  2. 智能体运行与排队数据复用工作区已有快照，不能可靠关联本机进程时显示资源不可用。
  3. LiWork 复用现有十秒缓存与会话校验，只统计已确认的会话；未确认和无采样明确标注。
  4. 界面每十秒刷新，仅在当前页面可见且窗口前台时轮询；页面采用应用主题和本地化。
  5. 测试采样单位与去重、异常值、页面空态、数据更新及离开后的轮询；运行桌面类型检查后启动开发版。

CPU 与内存是采样值，不对远程智能体或无法确认归属的进程推测占用；不重复将缓存页面计入总量。
